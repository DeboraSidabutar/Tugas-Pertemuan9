# Tugas Pertemuan 9

Automation testing menggunakan **Selenium WebDriver** + **Mocha**, lengkap dengan laporan **Mochawesome**.

## Cara Menjalankan

```bash
cd Tugas-Pertemuan9
npm install
npm run test
```

## Isi Folder

- `test/` : script pengujian (login & add user)
- `mochawesome-report/` : hasil laporan test
